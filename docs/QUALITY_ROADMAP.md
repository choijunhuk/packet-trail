# 다음 품질 개선 순서

기준: 1.2의 세 시나리오·44사건·Midnight OS. 아래 항목은 우선순위이며 완료 목록이 아니다. 기존 유효한 대안 해법과 저장 호환을 유지한다.

1. **반복 조작 개선.** 입력한 접두어로 터미널 기록을 탐색하고 브라우저의 익숙한 탐색 키를 제공한다. 빈 입력의 전체 기록, 편집 중 초안, 네 터미널 분리, 암호/IME/모달 보호가 수락 조건이다. 이번 구현 범위다.
2. **첫 20분의 학습 품질.** M01~M03에서 무엇을 조사하고 왜 접근이 거절됐는지 행동 결과로 설명한다. 힌트를 사용하지 않는 다른 유효 해법도 통과해야 한다. 초보와 숙련자의 실제 플레이에서 막힌 지점과 원인을 확인한 뒤 문구·단서를 조정한다.
3. **선택의 결과를 더 구체화.** 기존 사건의 회수 대상·전달 선택·서비스 보존이 후속 대화와 관찰 가능한 상태에 반영되는지 점검한다. 새 분기는 서로 다른 상태와 결과를 만들 때 추가한다. 결말 문구만 다른 경로를 새 퍼즐로 계산하지 않는다.
4. **앱별 시각적 개성.** 가상 사이트의 공공기관·사내 시스템·개인 보관소를 구분하고, 도구의 입력→관찰→성공/거절 표현을 일관되게 만든다. 기존 OS 창 조작과 텍스트 가독성을 유지하며 실제 렌더로 비교한다.
5. **검증 후 확장.** 첫 사건 품질과 기존 중반부의 반복도를 개선한 뒤 제한된 모바일 분석·리버싱 선택 사건을 평가한다. 기존 상태/도구를 재사용할 수 있고 독립적인 추론이 필요한 사건을 우선한다. 압박 난이도는 힌트 설정과 구분해 설계한다.

8~12시간은 사람의 첫 플레이를 측정해야 검증할 수 있다. 자동 해법 재생 시간으로 분량을 추정하거나 반복·강제 대기로 시간을 늘리지 않는다. 실제 사람의 재미·난이도·청취·원어민 교정과 각 OS 입력 수락은 별도다.

이번 협업: 리더 모델은 세션에서 확인된 `gpt-6-astra`이며 추론 수준은 노출되지 않아 단정하지 않는다. 입력 개선 담당은 요청 `gpt-6.1-sol / high`의 독립 Codex 세션이다. 이 기록은 이전 1.2 제작 당시 모델 기록을 수정하지 않는다.
