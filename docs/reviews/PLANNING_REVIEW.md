## 첫 판정: REVISE

| 발견 | 반영한 최소 수정 |

| 창 닫기가 세션 종료인지 유지인지 충돌 | 닫기는 표시만 종료, 앱 상태 유지. exit/로그아웃을 분리 |
| 미션별 초기화와 이전 선택의 영향 연결 미정 | 초기 번들+명시적 CampaignState 사실/정책 효과. 임의 원격 파일·세션 이월과 구분 |
| LearningState의 저장·리셋 정책 누락 | SaveEnvelope.learning 추가, 재시작 보존·복습 추가·디버그 격리 |
| 전역 revision 때문에 연속 증거가 서로 무효화될 수 있음 | 생성 시점과 관련 정책/대상/세션 의존 버전을 분리 |
