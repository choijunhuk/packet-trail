## 2. 기존 반영 초안에서 찾은 보완점

아래 세 항목은 **구현 전 문서 계약의 빈틈**이다. 존재하지 않는 게임에서 버그를 재현한 것으로 표시하지 않는다.

| 중요도·위치 | 문제 | 반영한 최소 보완 |
|---|---|---|
| P2 · ARCHITECTURE §3 | 목표가 참인 동안 조회/재회수마다 완료 효과를 추가할 수 있음 | 미완료→완료 전이에서 완료 표시·답장·다음 단서/보상을 같은 커밋에 한 번 적용. 완료 후 행동·저장 복원에서 중복 금지 |
| P2 · ARCHITECTURE §4, CURRICULUM M01 | ID만 같고 본문·출처가 바뀐 사본의 판정이 불명확 | 콘텐츠가 선언한 불변 기록의 ID+원본 데이터+허용 출처를 함께 검사. 변조 사본 실패·동일 웹 보관 사본 성공을 미래 fixture로 명시 |
| P2 · ARCHITECTURE §10 | 전체 WorldState의 원시 deep-equal은 UI/콜백/새 실행 세대·JSON 수치와 충돌 | 저장할 권위 상태 snapshot과 독립 기대 fixture를 비교. 누락 기본값 보정 금지, 검증한 수치 정규화만 허용 |

Godot JSON은 숫자를 float로 읽으므로 정수 필드는 숫자·유한성·정수성·범위 검사 후 int로 복원하도록 했다. 원문의 수치 의미를 바꾸는 숨은 offset과 이 타입 정규화를 구분한다. [Godot JSON](https://docs.godotengine.org/en/stable/classes/class_json.html)

Snapshot 비교는 안정적인 게임 값·완료/자료/후일담을 포함하고 Node·UI·콜백·런타임 핸들은 재구성한다. 기대 fixture를 같은 저장 필드 추출 함수로 만들면 양쪽의 누락을 놓칠 수 있으므로 독립적인 비기본 중첩 값을 사용한다. 새 지속 필드는 스키마와 기대 fixture도 갱신한다. [Godot 저장](https://docs.godotengine.org/en/stable/tutorials/io/saving_games.html), [Dictionary](https://docs.godotengine.org/en/stable/classes/class_dictionary.html)

## 3. 문서 검사기에서 실제 재현한 문제

기존 검사기를 격리된 저장소 사본에서 실행해 정상·고장 입력을 비교했다.

- 기본 인코딩을 ASCII로 둔 환경에서 UTF-8 한국어 문서를 읽다가 `UnicodeDecodeError`로 종료됐다.
- 필수 피드백/미션 파일 누락 또는 잘못된 UTF-8에서 결과 JSON 대신 traceback이 나왔다.

먼저 테스트를 추가해 11개 중 5개 실패를 확인한 뒤 최소 수정했다. 문서는 UTF-8로 읽고, 읽기/누락 오류를 결과에 모아 비영 종료하며, 출력 JSON은 ASCII escape를 사용해 콘솔 인코딩에 덜 의존하게 했다. 기존 정상 입력·깨진 파일 링크·앵커·JSON·선수 순환·피드백 변조 거절은 유지했다.

재현 가능한 검사:

```sh
python3 tools/check_docs.py
python3 -m unittest discover -s tools -p 'test_check_docs.py' -v
```

테스트는 실제 검사기 프로세스를 다른 작업 디렉터리에서 실행하며 원본 문서를 손상시키지 않는다. ASCII 기본 인코딩을 만든 것은 문자 인코딩 경계 시험이며 Windows/macOS/Linux의 게임 동작을 검증한 결과가 아니다.

## 4. 근거·범위

R2의 Hacknet 버그 서술은 Claude가 요약한 사용자 정적 보고서의 간접 근거로 기록한다. 이번에 상세 IL·원작을 추가로 열거나 실행하지 않았다. 같은 오류 유형을 막는 새 계약은 원작 버그의 독립 재현 없이도 합리적으로 채택할 수 있다.

새 설계 계층·의존성·게임 구현을 추가하지 않고 기존 코드/문서의 최소 누락을 보완했다. 캐릭터·OST·3OS·다국어·8~12시간 목표는 유지한다. 문서 및 검사기 검증과 게임/시각/학습 효과 검증은 구분한다.

최신 검사 수치와 독립 재검토 판정은 [검증 기록](../PLANNING_VALIDATION.md)에 남긴다.
