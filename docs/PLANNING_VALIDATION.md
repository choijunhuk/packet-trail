## 독립 검토

`gpt-6.1-sol / xhigh`가 작성자와 별도 맥락에서 피드백과 개정을 대조했다. 첫 검토에서 M01 명령 계약·기본 경보 음악·피드백 인용 범위를 보완했고 해당 항목 재검토 결과는 **READY — 문서 기준**이다. 초기 437118c의 READY를 새 개정에 그대로 재사용하지 않았다.

2차 개정은 작성 세션과 분리된 Claude Code 서브에이전트(sonnet, 읽기 전용)가 2차 원문 대비 diff를 검토해 **READY — 문서 기준**을 냈다. 지적 🟡 4건(링크 수, 세션 문장 2곳, `scp` 같은 이름 처리, M01 경보 테스트)과 🟢 1건(`alert_max` 상한 설명)을 반영했다. 접근성 단계 표기와 검사기 정규식 한계는 영향이 없어 보류했다.

캐릭터 문서와 연결 문서는 별도 **READY — 텍스트 기획 기준** 검토를 받았다. 실제 이미지 품질·정본 일관성·alpha·가독성·게임 연결 검수는 수행하지 않았다. 상세 이력은 `docs/reviews/PLANNING_REVIEW.md`에 남겼다.

2026-11-05에는 `gpt-6.1-sol / xhigh`가 R2 초안을 새로 대조해 완료효과1회·기록 원본/출처 무결성·지속 snapshot 비교 경계를 보완했고, 해당 문서·검사기 코드를 읽고 회귀 실행 증거를 확인해 **READY — 지정 검토 범위**를 보고했다. 상세는 `docs/reviews/CODEX_R2_REVIEW_20261105.md`다. 과거 READY를 이번 검증에 그대로 재사용하지 않았다.

## 실제/제공 근거의 구분

- 초기 작성과 R2 재검토의 모델/추론 수준을 `AI_WORKFLOW.md`에 시점별로 구분했다. 이번 리더는 실제 `gpt-6.1-sol/max`, 독립 검토 `xhigh`, 공식자료 확인 `high`였다.
- 1차 Claude 원문의 모델명은 전달 문서의 기재이며, 1차 개정(A08~A12)에서는 새 Claude를 호출하지 않았다. 2차 평가·개정은 Claude Code 세션(`claude-opus-5-5`)이 직접 수행했다(AI_WORKFLOW C06·C07). 이전 최소 응답 성공과 초기 자문은 별도 시점 이력으로 유지한다.
- Hacknet 사용자 정적 보고서의 실행 파일 크기·해시·plist·주요 경로/대표 XML 크기를 제한적으로 대조했다. IL 의미·전체 인벤토리·원작 실행은 재현하지 않았다. 이후 원작 설치 파일을 추가로 열지 않고 사용자 설명을 참고했다.
- 기존 JavaScript 예시의 Map/옵션 파싱 최소 재현은 초기 기획의 과거 검사다. 이번 게임 구현 테스트로 계산하지 않는다.

Godot JSON 수치·Dictionary 비교·저장 대상의 공식 자료를 대조했다. 이번에는 게임 코드를 실행한 것이 아니라 계약을 검증·정규화된 지속 snapshot과 독립 기대값 비교로 한정했다. 완료 효과 중복·기록 변조 거절 등은 앞으로 구현할 게임 회귀 조건이다.
