## 반드시 지킬 제품 계약

- 본편은 PC 설치형 게임. 게임 속 브라우저는 내부 사이트를 탐색한다.
- 한 사건에서 알려준 기술을 사용하지 않아도 목표·제약·근거가 유효하면 통과한다.
- 학습 미평가와 캠페인 완료를 분리한다. 증거 핀·퀴즈·특정 명령을 강제하지 않는다.
- 침투·조사·복구를 섞는다. 모든 사건이 취약점 수정 과제는 아니다.
- 포트 열림·구버전 배너만으로 익스플로잇을 성공시키지 않는다.
- 입력은 가상 상태에만 작용한다. 실제 shell·실제 네트워크·임의 코드 실행을 연결하지 않는다.
- Windows/macOS/Linux, 6개 언어, OST는 각각 제작·검증을 마친 뒤 지원 완료로 표시한다.
- 첫 플레이 빠른8시간/탐색12시간은 목표. 숙련자의 더 빠른 경로를 막지 않는다.
- Claude는 현재 추가 호출하지 않는다. 앞으로의 활용안과 이미 전달받은 결과는 구분한다.
