# 심야접속 — 다음 작업 시작점

현재 구현 상태는 [README](../README.md#현재-상태), 피드백 수용 판단은 [개정 기록](reviews/CLAUDE_FEEDBACK_RESPONSE_20261104.md)이 기준이다. 폴더·저장소 ID는 `packet-trail`을 유지한다.

## 다음의 작은 작업

1. **P0:** 개발 OS에서 Godot의 2D 데스크톱·터미널 하나·한글 입력·포커스·배율을 검증한다. 3D·OST·번역 팩·세 OS 전체 테스트를 선행 조건으로 넣지 않는다.
2. **P1:** M01 ‘첫 번째 야간 의뢰’를 의뢰→`guest` 접속과 거부→메모 단서→정비 계정 재접속→`scp` 회수→서윤의 답장/다음 단서→저장/재개까지 연결한다. 첫 게임 소스와 함께 실제 `tools/gate.sh`·콘텐츠 검사(빈 goals·미등록 kind 거절)·헤드리스 테스트(`record_id` 판정·저장 deep-equal)·경계 검사를 마련한다.
3. **P2:** M05/M09까지 도구 재사용·다중 해법을 검증한 뒤 3D 회색상자·ko/en 시험·세 OS 초기 export를 추가한다. 실제 각 OS의 완주·번역·OST는 MVP/출시 단계에서 검증한다.

상세 파일·완료 조건은 [ROADMAP_AND_QA](ROADMAP_AND_QA.md)를 따른다. 첫 미션의 실제 제작량과 재미를 확인하기 전 24개를 일괄 구현하거나 고급 증거/지연 작업 엔진을 먼저 만들지 않는다.

## 유지할 계약

- 제품은 설치형 게임, 최종 목표는 작은3D 작업실+가상OS·3OS·다국어·OST·빠른첫회8시간/탐색12시간이다.
- 기본 스토리 모드에 침투·회수 성공과 행동 경보의 피드백을 둔다. 읽기·오타·일시정지로 실패시키지 않는다.
- 새 도구를 이야기에서 배우고 이전 기술과 조합하되 숙련자의 다른 유효 경로를 허용한다.
- 목표와 제약은 현재 상태로 평가한다. 특정 도구·입력·힌트·퀴즈·pin은 통과 조건이 아니다.
- 학습 미평가를 숙달로 표시하지 않는다. 전체 학습 계측은 수요가 확인된 단계에서 추가한다.
- 창 닫기와 연결 종료를 분리하고, 다중 사건부터 이월 사실/정책을 명시한다. 서로 다른 읽기 관찰이 다른 관찰을 지우지 않게 한다.
- 실패한 행동의 부분 적용·저장 손실을 막고 입력은 가상 상태에만 작용하게 한다.

캐릭터 외형·생성 프롬프트는 [CHARACTER_ART](CHARACTER_ART.md)에 제안으로 정리돼 있다. P1은 서윤의 익명 아바타·의뢰 텍스트로 진행하며 완성 초상화나 추가 배역을 먼저 생성하지 않는다.
