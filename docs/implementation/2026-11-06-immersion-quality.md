# 시각·사용감·난이도 점검

상태: **1.2.1 구현·검증 완료.** 기준은 1.2와 이후 로컬 입력 개선이다. 별도 `feat/immersion-quality` 브랜치에서 기존 변경을 보존한다.

## 이번 변경 계약

Nightfox의 브라우저 조작 영역과 사이트 본문을 구분한다. 기존 가상 URL의 호스트·제목·본문·링크로 사이트 정체성과 읽기 계층을 만들며, 원문 선택/복사와 탭·폼·권한·과거 응답 경계를 유지한다. 상단 정보의 잘림과 도구 목록 발견성도 보완한다. 새로운 실행 의존성이나 실제 외부 웹을 추가하지 않는다.

기존 네이티브 캡처를 독립 검토하고, 현재 소스의 baseline을 다시 렌더한 뒤 변경 화면을 비교한다. 1600×900과1280×720 출력·큰 글씨·다국어 및 실제 키 입력 검증을 사용한다. 소스 자동 통과와 사람의 미적 승인·재미 판단은 구분한다.

## 난이도 판단

현재 `game.gd::_denied`의 경보는 접근 거부 시 증가하는 안내 수치다. 상한에 도달해도 공통 연결 차단·게임오버·실시간 추격은 실행하지 않는다. 따라서 경보 상한만 바꾼 쉬움/어려움은 실제 도전의 차이를 만들지 못한다.

가이드/표준/자율은 도움의 양이다. 자율에서도 요청형 도움을 이용할 수 있다. 현재 UI의 ‘목표·경보 규칙은 같다’ 설명을 유지한다. 첫 플레이에는 가이드를 권하고, 도구가 익숙해지면 표준·자율로 안내량을 줄이는 것이 적합하다.

실제 도전은 개별 모델의 인증 제한·정상 업무 보존·방어 조치/롤백·추적 관측/반례에 있다. 이를 사건별로 조합해야 난이도가 달라진다. VM 실행 한도를 줄이는 방식은 올바른 프로그램도 실패하게 하므로 난이도 설정으로 사용하지 않는다.

v2 저장은 정확한9키와 사건 정의에 따른 행동 재생 검증을 사용한다. 설정 슬라이더가 과거 저장의 규칙을 바꾸면 정상 진행을 복구하지 못할 수 있다. 이번 UI 개선에 전역 규칙 변경을 섞지 않는다.

후속 실제 난이도는 우선 독립 슬롯의 선택 도전 사건으로 도입한다. 표준88해법 유지, 도전별 두 유효 경로, 실패 후 복구, 정상 업무 보존, 새 게임 때 고정한 규칙으로 저장/불러오기 일치를 확인해야 한다. 전체 캠페인 난이도를 도입할 때는 `ruleset_id`를 저장하는 버전과 v2 원본을 보존하는 마이그레이션이 선행돼야 한다. 읽는 시간이나 입력 오타에 시간 벌점을 붙이지 않는다.

## 모델과 검증 소유

리더는 현재 `gpt-6-astra`(추론 수준 미노출), 난이도 읽기 전용 architect는 설치 역할의 `gpt-6-astra/high`, 시각 검토 designer는 `gpt-6-sol/medium`, 구현은 요청 `gpt-6.1-sol/high`, native QA test-engineer는 `gpt-6-sol/medium`이다. 요청 설정과 실행 결과를 구분하고 모델의 정적 의견을 실제 테스트로 표시하지 않는다. 이번 묶음의 최종 검증 결과는 완료 뒤 아래에 추가한다.

## 재현과 수정 증거

- 기존 화면을 독립적으로 점검한 뒤 현재 소스 baseline45PNG를 보존했다. 입력 접두어 기능과 충돌하던 예전 Up 검사는 불일치 초안 보존→빈 입력에서 실제 기록 회수→초안 복원으로 의미를 보존해 갱신했다.
- 첫 시각 변경은 사이트 문서 표면·호스트/제목/본문/링크 계층, 접속 정보 tooltip, 도구 이름 tooltip과 선택 시 스크롤 초기화를 구현했다. 새 실행 의존성과 새 번역 키는 없다.
- 기본 preview825/0 뒤 별도의 한국어·독일어1280출력·160%글씨·확장 폼을 시험해931검사 중22실패를 발견했다. 문서의 최소 높이 때문에 폼이 밀려난 실제 문제였다. 본문이 내용 높이를 사용하게 하고 기존 외부 스크롤을 재사용해 수리했다. 탭·주소·요청 주체·과거 응답 경고는 고정 영역으로 남겼다.
- 최종 집중 preview는926/0·12.301초·49PNG,21개 주소/폼 조작 도달 검사와 사용자 보호30항목 SHA 동일이다. 실제 M01 한 사건을 재생했으며 전편 검증과는 별도다. 후속 닫기 검사 실패는 QA의 마우스 휠 release 누락으로 판별해 실제 press/release를 완성했고, 제품 닫기를 우회하지 않았다.
- 독립 시각 검토는70/revise에서90/pass로 바뀌었다. 이는 확인한 화면의 정성 판정이며 사용자 미적 승인이나 물리 OS 시험이 아니다. 처음 의뢰 카드와 저장 알림의 중복 강조, 작은 독일어 화면의 상단 host 생략은 낮은 우선순위로 남았다. 전체 값은 tooltip과 전경 터미널/브라우저에서 확인할 수 있다.
- C24가 지적한 경보 상한 설명은 실제 구현과 대조해6언어 모두 수정했다. 개별 서비스 인증 제한과 전역 경보를 구분하며723 UI키·6언어각2,646키의 정합성·폰트 검사를 통과했다.

소스 검증: `bash tools/gate.sh` 종료0/PASS, 새 desktop189·browser414·support340·lobby105 및 공개44사건88해법14,110검사·legacy31,717·mutation1,217·Python49와 경계25스크립트가 통과했다. 별도 패키저10검사도 통과했다. 로그는 `.omx/artifacts/quality-pass/`에 보존한다.
