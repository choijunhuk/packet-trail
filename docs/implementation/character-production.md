# 캐릭터 정본·표정 제작 기록

2026-11-05 전체 제작 범위에서 [아트 바이블](../CHARACTER_ART.md)의 네 성인 허구 인물을 제작 정본으로 채택했다. 사용자 피드백을 대신한 승인 주장이 아니며 이후 외형 피드백을 반영할 수 있다.

## 실제 산출물

`godot/assets/portraits/`에 C01 서윤·C02 도윤·C03 민서·C04 태경의 `neutral`, `focused`, `guarded`, `relieved` PNG 16장을 저장했다. 각 인물의 중립 정본을 먼저 생성하고, 해당 정본만 참조하여 표정 세 개를 편집했다. 머리·의상·빛·각도·정체성을 유지하는 방향으로 선택했다.

내장 image_gen 도구와 imagegen 스킬을 사용했다. 도구가 모델 선택/실제 모델명을 노출하지 않아 특정 모델 이름이나 추론 수준을 추정하지 않는다. 실존 인물·원작 이미지·특정 작가의 그림체를 참조하지 않았다. 익명 얼굴은 단순 추상 표식으로 표현한다.

중립 생성 프롬프트 네 개는 아트 바이블의 C01~C04 영문 블록이다. 표정 편집은 같은 문서의 identity 보존 템플릿과 focused/guarded/relieved 치환문을 사용했다. 실제 입력 프롬프트·참조 경로는 로컬 `.omx/artifacts/full-production/portrait-prompts.json`, `portrait-variants.json`에 기록했다. 원본 생성 위치의 파일을 보존하고 작업트리에 복사했다.

출처·파일별 SHA-256·바이트·해상도는 [정본 manifest](../../godot/assets/portraits/SOURCE.json)에 있다. 16개 파일은 서로 다른 해시이며 RGBA PNG, 모두 1024px 이상의 크기다. 총 원본 파일 크기는 24,043,897바이트다. `godot/tools/validate_portraits.gd`가 실제 투명도·빈 이미지/불투명 사각형 거절·본문 실루엣·해시를 36항목으로 검사했고 PASS다. 이는 동일 인물의 정성 검수와 UI 축소 검수를 대신하지 않는다.

제공하지 않는 PSD 레이어·전신 3D 모델·리깅·측면 시트를 만들었다고 기록하지 않는다. 이 게임은 1인칭 거점과 2D 연락처 초상화를 조합한다.

## 이야기와 공개 범위

| 인물 | 등장 | 얼굴 표시 |
|---|---|---|
| C01 서윤 | M01 익명 연락 | M12 완료 후 플레이어가 본인 확인을 선택한 경우 |
| C02 도윤 | M02 소개 | 소개 맥락 뒤 |
| C03 민서 | M09 제보 | M16 완료 후 출처 확인을 선택한 경우 |
| C04 태경 | M15 연락 | M20의 책임 설명 뒤 |

코어가 만난 인물만 읽기 모델에 제공한다. 공개 선택은 세이브의 허용된 decision으로 저장하며 메인 목표·권한·다른 해법의 조건이 아니다. UI는 코어의 공개 여부를 우선하고 숨겨진 얼굴/배역 수를 미리 노출하지 않는다. 표정이 선악·배신·정답 판정을 대신하지 않는다.

## 남은 사람 검수

표정의 감정 강도와 번역 대사의 어울림, 작은 avatar 가독성은 실제 전체 UI 캡처와 최종 사용자 피드백에서 평가한다. 개별 PNG 검사를 전편 UI·사람의 선호 검증으로 표시하지 않는다.
