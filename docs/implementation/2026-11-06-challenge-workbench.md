# 1.3 종합 도전·분석 작업대

상태: **1.3 구현·최종 검증 완료.** 기존1.2.1 릴리스는 보존한다.

## 제품 변화

새 `challenge` 팩은 별도 `midnight_challenge@1` 정체성과 `challenge_01.json` 슬롯을 쓴다. X01~X03 및 ch1_handoff 결말을 추가하며 기존3편44사건/88해법과 legacy 정의를 수정하지 않는다. 도움 수준은 별도 가이드/표준/자율이며 네 번째 지원 선호가 생긴다. 전체는47사건/94검증경로이며94개의독립퍼즐이라는 뜻은 아니다.

- X01: 민원 접수를 유지하면서 객체 접근과 반복 인증을 제한한다. 직접수리와 승인중계는 실제정책/endpoint가다르다. 먼저여러요청을시험해도정상해법으로복구가능해야한다.
- X02: 제한권한으로 실제배포파일을갱신하고 허용범위에만통지한다. 직접/승인해법은 실제파일과endpoint가다르며, 파일이오염된상태에서권한만복구해도완료되지않는다.
- X03: 공유주소/클라이언트표식에근거한오판을반박하고, 서로다른시계오차와전달경로를조합한다. 현장·수신기록을결합하거나 별도감사권한으로독립export를확보한다. 단일일반센서만으로완료되지않는다.

도구는 관찰과 행동·결과를 독립 스크롤 영역으로 나눈다. 빈보조기록을접어정보량을줄이되 모든공개필드/행상세를열어볼수있다. 펼침/선택은현재행이유효할때유지하고, 새세계와사라진행은초기화한다. 현재목표는기존사건보드로연결된다. 처음안내중자동저장알림은축약하지만 명시적벨읽기와중요실패안내를유지한다.

## 변경 경계와 재사용

콘텐츠는 새generator/pack/KOEN/fixture5파일로분리하고 기존생성기의순수헬퍼만재사용한다. catalog/고정slot·선호enum·locale/pck/native/CI의정확한공개범위검사를확장했다. v2최상위9키저장구조는그대로다. 기본44/88과추가3/6을각각검사한다.

`response_lab.gd`에는새endpoint만쓰는opt-in 두가지를추가했다. `current_content`는실제쓰기결과의현재내용을검증하고, `allowlist_policy`는허용목록을켜고끄는실제통지효과를구분한다. 기존정의에는필드가없어원래basis/통지규칙을유지한다. `campaign_model_schema.gd`가잘못된타입/operation/중복legacy정책을거절한다. 새OS·외부통신·실행의존성은없다.

UI주요파일은 `campaign_desktop.gd`, `room.gd`, `settings_panel.gd`다. `full_game.gd`는기존catalog구조가새팩을처리해수정하지않았다. 도구/파일/관측모델과기존목표/세션/기록표시를재사용했다.
