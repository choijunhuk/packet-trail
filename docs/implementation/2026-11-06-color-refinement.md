# 앱별 색 역할 개선

사용자가1.3의남색/회색반복을거부했다. 같은OS조작과콘텐츠를유지하면서앱별색역할과읽기표면을구분한다. 구현은요청gpt-6.1-sol/high, 리더Astra는검증/통합을담당한다.

- 공통쉘/중립표면은차콜, 앱별제목/선택/활성경계를명확히구분.
- 터미널민트, 분석도구청록, 메일따뜻한구리, 브라우저보라, 파일파랑을기본역할로선택.
- 경고/오류/성공의의미는보존하고색만으로상태를전달하지않는다.
- 읽기표면/필드/선택/포커스/hover상태까지검사. 공유StyleBox변경이타앱으로번지지않게한다.
- 기능/세계/저장/새텍스트·의존성변경은범위밖. 실제캡처와대비계산·회귀검사결과를완료뒤기록한다.

## 소스·실제 화면 검증

Sol6.1 구현은 `desktop_theme.gd`와 `campaign_desktop.gd` 두 파일에 한정했다. 기존 Theme 생성자에 accent를 전달하고 창별 독립 스타일/Theme를 재사용하며, 활성화·글씨크기·언어 갱신에서도 색 역할을 유지한다. 새설정·본문·게임규칙·저장구조·벽지는바꾸지않았다.

대비44조합 PASS, 순차 import→desktop228/0→workbench78/0, 보호34경로불변. 첫 실행의 import/test 동시실행 로그와 이후 순차검증을 구분했다. 실제nativepreview는1,270/0·18.236초·71PNG, 보호34경로·source345 SHA 불변·오류/경고0이다. 기본65장에활성앱별5장/동시제목줄1장을추가했고,비교배치의열기전0geometry복원실패2회는QA설정에서고쳤다. 제품의닫기검사를우회하지않았다.

Root는실제동시앱·브라우저·터미널캡처와대비표를독립확인해92/pass로기록했다. 사용자미적승인이나색각시뮬레이션/정식접근성인증은아니다.1280출력은기존1600논리캔버스의축소이며일반화하지않는다.

전체 `tools/gate.sh`는 종료0/PASS이며 기존47사건94해법·독립도전686·Python51·현지화와 실행 경계를 확인했다. 이번 색상 전용 변경에서는 전편47 GUI를 다시 재생하지 않았고 새로운71장 preview와 입력/기능 회귀를 검증했다. 이전1.3 전편6284 결과를 이번 실행으로 표시하지 않는다.
