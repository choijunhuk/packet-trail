# 입력 편의 개선 · 2026-11-06

범위는 기존 가상 OS의 터미널 기록과 Nightfox 키보드 조작이다. 화면 배치·에셋·세계 판정·저장 형식은 변경하지 않는다.

- 터미널 위/아래는 처음 작성하던 초안을 접두어로 사용해 일치하는 기록만 찾는다. 빈 초안은 전체 기록을 순회하며, 가장 오래된 일치 기록에서는 멈추고 가장 최근 일치 기록 뒤에서는 원래 초안으로 돌아온다. 불러온 기록을 수정하면 수정본으로 새 검색을 시작한다. 기존 터미널별 `draft`/`hist_idx`를 재사용하며 추가 저장 상태는 없다.
- Nightfox 전경에서 Alt+왼쪽/오른쪽은 기존 뒤/앞 버튼의 `_br_go`, Ctrl/Cmd+R 및 F5는 기존 새로고침 버튼의 `_br_reload`를 사용한다. 주소 초안이 있어도 현재 로드된 페이지를 새로 요청하고 이력을 추가하지 않는다. Alt 탐색은 다른 수정 키와 조합하지 않는다.
- 기존 단축키와 충돌하지 않는다. 새 브라우저 동작은 비밀 입력칸에 포커스가 있으면 실행하지 않으며, 기존 `_input`의 글자 조합·확인창·일시정지 보호 뒤에서 처리한다. 기존 터미널 암호/자동완성 보호를 유지한다.

검증은 기존 `test_desktop_shell.gd`에 추가했다. 접두어 일치/불일치·양 끝 경계·초안 복구·기록 수정·빈 초안·독립 터미널·암호 보호를 확인한다. 브라우저 키는 `_handle_shortcut` 직접 호출 대신 Viewport에 누름/뗌 이벤트를 전달해 입력 경로를 확인하며, 터미널 전경·암호칸·확인창·일시정지·추가 수정 키 조합을 포함한다.

검증 명령:

```sh
godot --headless --editor --path godot --import
godot --headless --path godot --script res://tools/run_desktop_shell.gd
```

Godot 4.7에서 헤드리스 **170 checks / 0 failures**. 최초 실행의 누락된 SVG import cache를 가져온 후 재검증했으며 Godot 오류 없이 통과했다. 새 사례가 없는 기존 구현에서는 접두어/키보드 조작 관련 14개 검증이 실패했다. 테스트는 고유한 `user://tests/desktop_shell_<pid>_<ticks>/` 아래에만 저장하고, 기본 저장·선호·진행 경로 30개의 실행 전후 fingerprint가 동일함을 검증한 뒤 자기 테스트 폴더만 지운다.

물리 키보드·실제 OS 단축키 선점·물리 IME 수용 검증은 **NOT_RUN**이다. 글자 조합 보호 분기는 기존 코드 순서를 유지했고 정적 확인했으며 물리 IME 시험으로 간주하지 않는다. 통합 gate와 수동 플레이는 별도 검증이다.

## 통합 검증

부모가 수정 소스에서 `bash tools/gate.sh`를 실행해 종료0과 최종 PASS를 확인했다. 공개44사건·88해법14,110검사, 보존 캠페인31,717검사, browser414·support340·desktop170·lobby105·mutation1,217 및 정상 종료8/6이 통과했다. 문서·현지화·runtime25스크립트 경계 검사도 통과했다. 원본 로그는 `.omx/artifacts/interaction-quality/whole-gate.log`다.

이번 변경은 로컬 소스에 있으며 커밋·새 설치본 배포는 하지 않았다. 기존1.2 릴리스의 검증과 이번 소스 검증을 구분한다. 다음 확장 순서는 [품질 개선 순서](../QUALITY_ROADMAP.md)를 따른다.

이후 위 입력 변경을 [1.2.1 시각·난이도 개선](2026-11-06-immersion-quality.md)에 통합해 전체 소스/패키지/CI를 다시 검증했다. 위 로컬 전용 상태는 이 문서의 첫 작업 시점 기록이다.
