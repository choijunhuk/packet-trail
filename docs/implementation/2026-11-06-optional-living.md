# 선택 의뢰와 작은 생활 공간 · 2026-11-06

상태: **1.4.0-rc1 — 구현·3OS CI·패키지 검증 완료**. 이 기록은 검증된 범위와 남은 수락 조건을 구분한다.

## 현재 구현 범위

- 기존 네 메인 선택·47사건·94해법은 유지한다. 선택 의뢰 I01(IAM)과 I02(공급망·배포·보고)는 각각 두 경로가 있는 별도 선택 콘텐츠다. 서로 선수 조건이 없고 본편 완료에도 필요하지 않다.
- OS·사건 보드에서 의뢰를 시작/재개하고 본편으로 돌아온다. IAM은 정상 업무와 과도 권한을 함께 평가한다. 공급망은 가상 파일 digest·출처·빌더·배포·서비스 결과를 결합하고 유지보수자/기자 보고에 따라 회신·후속 검증·기사가 달라진다. 의뢰 완료가 다른 의뢰나 엔딩을 강제로 열지 않는다.
- 의뢰는 `investigation_01.json`, 생활 상태는 `habitat_01.json`에 저장한다. 기존 캠페인 슬롯과 분리하며 생활 지갑·소유·장착·통신함 상태는 저장된 행동을 재생해 검증한다.
- 작은 3D 작업실↔안뜰을 왕복하며 벤치에서 새벽/밤 분위기를 고른다. 상점 주문→안뜰 배송 보관함 수령→키보드·모니터·조명 고정 슬롯 장착이 생활 루프다.
- 카탈로그는 기본 3종과 구매 5종, 총 8종이다. 시작 생활 크레딧 1,500으로 총 1,320인 구매 물품을 모두 살 수 있다. 외형 꾸미기이며 실제 결제·외부 네트워크를 사용하지 않는다.
- 게시판의 선택 통신함 일감은 수락→현장 조사→경로/잠금 설정→결과 검증이다. `service` 또는 `approved_relay`와 잠금으로 정상 원격 계측을 유지하면서 무단 접근을 차단한다. `off`는 정상 계측을 실패시킨다. 보상은 200 생활 크레딧을 한 번만 지급한다.

## 범위 변경과 경계

최초 선택 의뢰 PRD의 새 3D 상호작용 제외는 이후 사용자의 명시적 생활·꾸미기·야외 공간 요청으로 대체했다. 선택 의뢰의 독립성과 본편 보존 계약은 유지한다. 전역 명성·집단 가입, 거대한 도시, 가구 자유 배치, 허기 관리·반복 노동·강제 서브 퀘스트는 포함하지 않는다.

최대 12시간까지의 분량은 사용자 목표다. 사람의 실측 플레이 시간이나 현재 달성한 체류 시간으로 주장하지 않는다.

전체 gate 도중 마지막 생활 모델의 과거 중복 설정 반례가 추가되어 해당 최종 모델1,068검사를 별도로 다시 실행했다. 본편 GUI 첫 실행의2실패는 본편에서 선택 의뢰 전용 모델 사용을 요구한 검사 범위 오류였고, 기대 모델을 분리한 뒤47사건을 다시 완료했다.

독립 검토는 분전함 실험 기록 한도 고갈과 실행 중 손상 시 복구 UI 누락을 지적했다. 실패를 재현한 뒤 기록 압축·현재 복구 상태 전달을 수정했다. 기존 저장 계층·확인 대화상자·프리뷰 구조를 재사용했고 의존성이나 저장 형식을 늘리지 않았다. Claude 읽기 전용 검토는600초/300초 제한으로 모두 완료 응답이 없어 검토 완료로 세지 않는다.

[3OS CI](https://github.com/choijunhuk/packet-trail/actions/runs/42213402265)의 macOS·Windows·Linux 세 작업이 모두 성공했다. Windows/Linux 물리 GUI, 장시간 음향 청취·IME, 원어민 번역, 사람8~12시간 실측은 NOT_RUN이다. 자동화의 카메라 접근 위치 설정과 실제 E/버튼/Run 입력을 구분한다.
