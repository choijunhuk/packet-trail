# 전체 진행 수동 저장과 실제 게임 창 연출

상태: `1.5.0-rc1` 검증 중. 기존 `1.4.0-rc1` 릴리스는 보존한다.

## 플레이어가 사용하는 기능

시작 화면과 데스크톱에서 수동 저장/불러오기를 열면 전역5칸을 고를 수 있다. 각 칸은 저장한 현지 날짜·시간, 시나리오, 현재 의뢰와 진행도를 표시한다. 덮어쓰기와 불러오기는 확인 후 실행된다. 본편4편, 선택 의뢰, 이전판 이어하기, 방 꾸미기/생활을 함께 복원한다. 환경 설정은 현재 값을 유지한다. 자동 저장과 수동 저장의 버튼을 구분했다.

게임 재실행은 시작 메뉴로 들어온다. 수동 불러오기를 명시적으로 실행한 경우에만 저장했던 데스크톱/작업실/안뜰 문맥으로 돌아간다. 복원한 시점에 시작하지 않았던 편은 이후에 생긴 진행으로 부활하지 않는다. 이전판 원본은 별도 명시적 가져오기로 복사할 수 있으며 자동으로 섞지 않는다.

실제 바탕화면 연출은 설정에서 저장한 동의가 있어야 한다. 게임 자신의 창 제목과 위치를 최대12px,1.2초 동안만 바꾼다. 미리 보기와 I02 완료 시점에 연결했으며 기본값은 꺼짐이다. Esc로 건너뛸 수 있고 취소·설정 해제·종료 시 복원한다. 사용자가 창을 직접 움직이거나 제목이 다른 게임 동작으로 바뀌었다면 그 변경을 덮어쓰지 않는다. 창 비활성/헤드리스는 실행하지 않고, 동작 줄이기·전체화면·작은 창은 이동을 억제한다. 다른 앱, 실제 파일, 클립보드, 전역 키 입력, 외부 프로세스는 조작하지 않는다.

## 저장과 복구

각 수동 슬롯은 불변 세대의 개별 캠페인/생활 파일을 가리킨다. 복원은 새 활성 세대를 모두 검증·준비한 뒤 포인터 하나를 마지막에 교체한다. 각 캠페인2MiB·생활64KiB 제한은 유지하며 여러 캠페인의 합계를 한 파일 제한에 끼워 맞추지 않는다. 메모리의 모든 데스크톱을 교체해 다른 편으로 이동해도 복원 전 상태가 재등장하지 않게 했다.

손상 시 정상 자동 저장 백업이나 수동 슬롯 백업을 명시적으로 선택할 수 있다. 한 세대 안에서만 구성원을 검증하고, 그 세대 자체가 복구 불가능하면 이전 정상 세대 전체를 별도 안내한다. 서로 다른 세대의 구성원을 섞지 않는다. 손상되거나 참조가 불확실한 세대는 보존 표시를 해 자동 정리에서 제외한다. 활성 이력이 있는데 포인터가 유실되면 원래 고정 저장으로 조용히 돌아가지 않고 복구 화면에서 멈춘다.

원래 고정 저장·사용자 파일은 정리하지 않는다. 정상 동작에서는 참조되지 않는 내부 생성 세대만 정리하고, 현재/백업 포인터와 준비 중 세대는 보호한다. 손상1회 후105회 추가 복원에서도 테스트의 활성 세대는4개 이하로 유지됐다.

첫 활성 선택의 기록 후 마지막 교체가 실패하면 현재 메모리 진행은 보존되지만 재실행은 명시적 복구가 필요할 수 있다. 기존 flush/rename 방식에 대해 정전까지 보장하는 fsync 내구성을 주장하지 않는다. 동시 여러 게임 프로세스의 동일 저장 폴더 공유는 검증 범위가 아니다.

## 검토와 검증

Claude Opus5.5 high의 저장/UI/모델 검토3건, 수정본 후속 검토1건을 실제 수신했다. 이어 새 수동 저장/통합 검토2건도 정상 수신했다(저장232.20초, 통합183.37초). 소스만 읽은 지적을 재현 테스트와 실제 렌더링으로 검증하고, 기존 의도된 대체 경로를 막는 제안은 기각했다. [원래 확장 재검토 기록](../reviews/CLAUDE_REREVIEW_20261106.md).

수동 저장 후속 검토에서 발견한 불확실 세대 삭제, 포인터 유실 후 고정 저장 폴백, 마지막 정상 백업 상실은 RED10건을 재현한 뒤 수정했다. 독립 아키텍처 검토도 최종 수정 범위에 남은 차단 결함이 없음을 확인했다. UI 검토의 메뉴 로드 후 포커스, 오래된 문맥 자동 진입, 명시적 이전판 가져오기, 모드 변경 전 연출 취소를 보완했다. 성공 응답이면 항상 ready인 생활 모델의 모순된 가설과, 수동 창을 여는 것만으로 경보 타이머가 진행한다는 가설은 현재 코드와 맞지 않는다.

집중 검사: 수동 저장167/0, 통합UI383/0, 창 연출64/0, 생활1,125/0, IAM182/0, 공급망138/0. 전체 gate PASS(기존94경로 포함), 최종 네이티브 수동 저장693/0·18PNG·기본경로52개 지문 동일·0사건풀이/0엔딩을 확인했다. 한국어/독일어1280×720·1.6배에서 다섯째 슬롯과7구성원복구 안내를 검증했고 시각판정95/pass다. 실제 창이 집중된 초회실행에서 제목·12px이동·복원을 관측했으나 그 전체회차는 다른 테스트설정실패가 있었고, 최종회차에서는 창비활성으로 해당연출NOT_RUN이다. 두근거를섞어최종회차의물리연출통과로주장하지않는다. 3OS CI·패키지 결과는 완료 후 갱신한다. 실제 창 효과와 가짜 드라이버 단위 검증, 모델 설정을 준비한 테스트와 실제 UI 입력은 구분한다.
