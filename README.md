# Packet Trail · 패킷 트레일

[GitHub 저장소](https://github.com/choijunhuk/packet-trail) · 비공개 · 기획 단계

**작은 3D 작업실과 게임 속 데스크톱에서 터미널·해킹 도구·가상 브라우저를 열고, 네트워크를 조사하며 보안 개념을 배우는 한국어 게임.**

Hacknet의 터미널 몰입감에서 출발하되, 독자적인 도시 통신망 복구 이야기와 ‘정찰 → 접근 경로 선택 → 사건 목표와 제약 검증’을 결합한다. 이 저장소는 **기획 단계**다. 실행 가능한 게임과 교육 효과 검증은 아직 없다.

## 제안한 제품 규모

| 단계 | 콘텐츠 목표 | 검증 목적 |
|---|---|---|
| 수직 시제품 | M01·M05·M09, 25~40분 | 입력감·퍼즐·학습 루프가 함께 작동하는가 |
| MVP | M01~M10, 90~150분 | 안내 없이 다음 문제를 풀 수 있는가 |
| 1.0 | 6장·메인 24개+선택 사건 4개, 8~12시간 | 캠페인·성장·복습·배포 품질을 완성할 수 있는가 |

수량·시간은 설계 목표다. 3미션 시제품을 최종 게임 전체로 취급하지 않는다.

## 기술 방향

**제품 방향: PC 설치형 게임. 엔진 권고: Godot 4+GDScript.** 작은 3D 작업실에서 컴퓨터를 사용하면 전체 화면 데스크톱에서 여러 터미널, 해킹 도구, 메일, 가상 웹사이트를 창으로 연다. 브라우저는 게임 내부 앱이다. Hacknet의 실제 기술과 새 엔진 권고는 [조사 문서](docs/PRODUCTION_RESEARCH.md)에서 구분한다.

가상 사이트·계정·파일·서버를 하나의 내부 시뮬레이터로 연결한다. 터미널과 도구는 같은 상태를 사용한다. 플레이어가 입력한 명령은 실제 OS 명령이나 외부 인터넷 접속으로 실행하지 않는다.

## 현재 상태

- 상세 기획·기술·교육·검증 문서와 비공개 저장소를 준비했다. 독립 검토 결과는 [기획 검토 기록](docs/reviews/PLANNING_REVIEW.md)에 있다.
- 모델과 추론 수준은 [AI 작업 기록](docs/AI_WORKFLOW.md)에서 권장값과 실제 실행값을 구분한다.
- 게임 코드, 테스트 실행, 플레이테스트, 배포는 아직 수행하지 않았다.
- 구현을 시작하기 전 [다음 작업](docs/HANDOFF.md)의 기술 검증부터 진행한다.
