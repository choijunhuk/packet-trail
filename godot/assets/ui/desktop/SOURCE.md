# Midnight OS original desktop artwork

The wallpaper and SVG icons in this directory were authored directly for Packet Trail on 2026-11-06, using geometric paths and the project palette. No Kali, Windows, Firefox or Chrome logos, wallpapers, screenshots, fonts or third-party icon packs were copied.

- `wallpaper.svg`: original abstract night landscape.
- Other SVGs: original interface symbols with a consistent 1.7-unit stroke.
- UI typography continues to use the separately attributed project font assets.
- These original assets follow the project’s distribution terms.
